Вход в аккаунт

Библиотека синхронизируется между устройствами через приватный GitHub Gist. Данные хранятся только на вашем GitHub-аккаунте.
Классический токен со scope gist. Хранится только в этом браузере.
Оставьте пустым на первом устройстве — Gist создастся автоматически. На втором устройстве вставьте Gist ID с первого.
Как получить токен?
  1. Откройте github.com/settings/tokens
  2. Нажмите Generate new token (classic)
  3. Поставьте галочку только напротив gist
  4. Скопируйте токен (ghp_...) и вставьте сюда
  5. Токен хранится только в вашем браузере, никуда не отправляется
